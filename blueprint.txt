User
├── id
├── username (unique)
├── email (unique)
├── hashed_password
├── native_language (SupportedLanguage)
├── created_at

PracticeSession
├── id
├── user_id (FK → User)
├── target_language (SupportedLanguage)
├── support_language (SupportedLanguage)
├── conversation_config (ConversationConfig)
├── practice_mode (PracticeMode)
├── proficiency_level (ProficiencyLevel)
├── scenario_type (ScenarioType, nullable)
├── topic (String, nullable)
├── status (SessionStatus, default=active)
├── assemblyai_agent_id (String, nullable)
├── started_at
├── ended_at (nullable)
├── duration_seconds (int, nullable)

ConversationMessage
├── id
├── session_id (FK → PracticeSession)
├── speaker (enum: user, agent)
├── content (Text)
├── language (SupportedLanguage)
├── timestamp

SessionEvaluation
├── id
├── session_id (FK → PracticeSession, unique)
├── overall_score (Float)
├── grammar_score (Float)
├── vocabulary_score (Float)
├── fluency_score (Float)
├── comprehension_score (Float)
├── pronunciation_score (Float, nullable)
├── target_language_percentage (Float)
├── feedback (Text — JSON)
├── recommendations (Text)
├── evaluated_at

Mistake
├── id
├── session_id (FK → PracticeSession)
├── user_id (FK → User)
├── original_text (Text)
├── corrected_text (Text)
├── mistake_type (enum: grammar, vocabulary, fluency)
├── explanation (Text)
├── created_at

UserProgress
├── id
├── user_id (FK → User)
├── target_language (SupportedLanguage)
├── sessions_count (int, default 0)
├── total_practice_minutes (int, default 0)
├── avg_overall_score (Float, default 0.0)
├── avg_grammar_score (Float, default 0.0)
├── avg_vocabulary_score (Float, default 0.0)
├── avg_fluency_score (Float, default 0.0)
├── best_score (Float, default 0.0)
├── current_streak (int, default 0)
├── longest_streak (int, default 0)
├── last_practice_date (Date, nullable)
├── updated_at



AUTH:
UserCreate     → username, email, password, native_language
UserResponse   → id, username, email, native_language, created_at
TokenResponse  → access_token, token_type

SESSIONS:
SessionCreate  → target_language, support_language, conversation_config,
                 practice_mode, proficiency_level, scenario_type, topic
SessionResponse → all fields
SessionUpdate  → status, ended_at, duration_seconds

MESSAGES:
MessageCreate  → session_id, speaker, content, language
MessageResponse → id, session_id, speaker, content, language, timestamp

EVALUATION:
EvaluationResponse → all score fields + feedback + recommendations

MISTAKES:
MistakeResponse → id, original_text, corrected_text, mistake_type, explanation

PROGRESS:
ProgressResponse → all progress fields per language

AGENT CONFIG:
AgentConfigRequest → session_id (used to build dynamic agent prompt)
AgentConfigResponse → agent_id, config



USER:
get_user_by_username(db, username) → User | None
get_user_by_email(db, email) → User | None
create_user(db, user: UserCreate) → User
authenticate_user(db, username, password) → User | None

SESSIONS:
create_session(db, session: SessionCreate, current_user: User) → PracticeSession
    → creates session record
    → creates/updates UserProgress record for that language
    → returns session

get_my_sessions(db, current_user, page, limit) → dict (paginated)
get_session_by_id(db, session_id, current_user) → PracticeSession | None
update_session(db, session_id, update: SessionUpdate, current_user) → PracticeSession | None
    → used to end session (status=completed, ended_at, duration_seconds)

MESSAGES:
save_message(db, message: MessageCreate) → ConversationMessage
get_session_transcript(db, session_id, current_user) → list[ConversationMessage]

EVALUATION:
create_evaluation(db, session_id, evaluation_data: dict) → SessionEvaluation
    → saves all scores and feedback
    → updates UserProgress averages
    → updates streak
get_session_evaluation(db, session_id, current_user) → SessionEvaluation | None

MISTAKES:
save_mistakes(db, session_id, user_id, mistakes: list[dict]) → list[Mistake]
    → bulk insert all mistakes from one session
get_my_mistakes(db, current_user, language=None) → list[Mistake]
    → optionally filter by target language of session

PROGRESS:
get_or_create_progress(db, user_id, language: SupportedLanguage) → UserProgress
    → if no record exists for this language, create one with all zeros

get_my_progress(db, current_user) → list[UserProgress]
    → returns progress for ALL languages user has practiced

get_progress_by_language(db, current_user, language) → UserProgress | None

update_progress(db, user_id, language, evaluation_data: dict) → UserProgress
    → called after evaluation is saved
    → updates:
        sessions_count += 1
        total_practice_minutes += session duration
        recalculate avg scores (running average)
        update best_score if new score is higher
        update streak (same as medication tracker pattern)
        update last_practice_date




services/gemini.py:

evaluate_session(transcript: list[dict], target_language, support_language,
                 conversation_config, proficiency_level) -> dict
    → analyzes full transcript
    → returns scores for all categories
    → returns list of mistakes with corrections
    → returns personalized recommendations
    → returns target language usage percentage

generate_recommendations(mistakes: list, progress: dict) -> str
    → looks at recurring weaknesses
    → generates specific next practice suggestion

services/agent.py:

build_agent_config(session: PracticeSession) -> dict
    → builds the JSONC agent config dynamically
    → sets correct language for AI voice
    → sets system prompt based on:
        - practice mode (free/scenario/tutor)
        - proficiency level (beginner/intermediate/advanced)
        - scenario type (restaurant/airport/hotel etc)
        - topic (if free conversation)
        - conversation config (who speaks what language)
    → returns config dict to publish to AssemblyAI

GET /progress/{language}         → progress for specific language

MISTAKES:
GET /mistakes/                   → all my mistakes (filterable by language)
GET /mistakes/{language}         → mistakes for specific language
